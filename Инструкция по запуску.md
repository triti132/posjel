# Инструкция по запуску проекта Education Platform

Эта инструкция поможет запустить проект с нуля, даже если на твоем компьютере ничего не установлено.

---

## Что потребуется установить

| Инструмент | Версия | Зачем нужен |
|---|---|---|
| JDK | 21+ | Для компиляции и запуска Java-кода |
| IntelliJ IDEA | Community (бесплатная) | Удобная IDE для разработки |
| Git | Последняя | Для клонирования репозитория |
| Docker Desktop | Последняя | Для запуска PostgreSQL в контейнере |
| Postman (_опционально_) | Любой | Для тестирования API|

---

## Шаг 1. Установка JDK 21

### Для Windows:

1. Перейти на сайт [Adoptium](https://adoptium.net/temurin/releases/?spm=a2ty_o01.29997173.0.0.185dc9216l1dPA&version=21).
2. Скачай **JDK 21 для Windows** (x64, `.msi` формат).
3. Запусти установщик. При уставовке **обязательно отметь галочку** `Set JAVA_HOME variable` и `Add to PATH`.
4. После установки открой **Командную строку** и проверь:

``` bash
java -version
```

Должно вывести `openjdk version "21.x.x" ...`

### Для macOS:

1. Установи [Homebrew](https://brew.sh/?spm=a2ty_o01.29997173.0.0.185dc9216l1dPA) (если еще не установлен):

``` bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

2. Установи JDK 21:

``` bash
brew install openjdk@21
```

3. Проверь:

``` bash
java -version
```

## Шаг 2. Установка Git

### Windows:

1. Скачай с [git-scm.com](https://git-scm.com/download/win?spm=a2ty_o01.29997173.0.0.185dc9216l1dPA).
2. Установи, оставляя все настройки по умолчанию.
3. Проверь в командной строке:

``` bash
git --version
```

### macOS:

``` bash
brew install git
git --version
```

## Шаг 3. Установка Docker Desktop

Docker нужен для запуска PostgreSQL в изолированном контейнере - не нужно устанавливать базу вручную.

1. Перейти на [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/?spm=a2ty_o01.29997173.0.0.185dc9216l1dPA).
2. Скачай и установи Docker Desktop для своей ОС.
3. После установки **запусти Docker Desktop** и дождись, пока в трее появится значок кита с надписью `Engine running`.
4. Проверь в терминале:

``` bash
docker --version
docker-compose --version
```

## Шаг 6. Запуск базы данных PostgreSQL

В корне проекта есть файл `docker-compose.yml`, который поднимает PostgreSQL на порту `5433`.

``` bash
# Запуск контейнера с PostgreSQL в фоне
docker-compose up -d

# Проверь, что контейнер запущен
docker ps
```

Ты должен увидеть контейнер с PostgreSQL. Параметры подключения (уже прописаны в `application.yml`):

- **Хост:** `127.0.0.1`
- **Порт:** `5433`
- **База:** `education_db`
- **Пользователь:** `postgres`
- **Пароль:** `postgres`

> Чтобы остановить БД: `docker-compose down`
> Чтобы остановить и удалить все данные: `docker compose down -v`

## Шаг 7. Открытие проекта в IntelliJ IDEA

1. Запусти IntelliJ IDEA.
2. Выбери **Open** (или `File -> Open`).
3. Укажи папку `education-platform', которую ты склонировал.
4. IDEA автоматически:
   - обнаружит `pom.xml` и предложит импортировать Maven-проект;
   - скачает все зависимости;
   - настроит JDK 21.

> Если IDEA просит выбрать SDK, укажи установленный JDK 21.

Дождись, пока в правом нижнем углу исчезнут все индикаторы загрузки (индексация, скачивание зависимостей).

## Шаг 8. Запуск приложения

Перед запуском задай секрет для подписи JWT. Не добавляй его в `application.yml` и не коммить в репозиторий.

```bash
# macOS/Linux: для текущего окна терминала
export JWT_SECRET="$(openssl rand -base64 48)"
```

В Windows PowerShell:

```powershell
$env:JWT_SECRET = "вставь-длинную-случайную-строку-не-меньше-32-символов"
```

### Вариант А - через IDEA (рекомендуется):

1. Открой файл `src/main/java/com/education/EducationApplication.java`.
2. Нажми на зеленую стрелку ▶️ рядом с `public static void main' -> **Run 'EducationApplication'**.

### Вариант Б- через терминал:

``` bash
# В корне проекта (mvnw - это встроенный Maven Wrapper, ничего устанавливать не нужно)

# Для Windows:
mvnw.cmd spring-boot:run

# Для macOS/Linux:
./mvnw spring-boot:run
```

При первом запуске:

- Flyway применит все миграции (создаст таблицы).
- Spring Boot поднимется на порту `8080`.

В консоли ты должен увидеть:

```
Started EducationApplication in X.XXX seconds
```

## Шаг 9. Проверка, что все работает

Открой браузер или Postman и выполни:

``` bash
# Проверка, что сервер отвечает
curl http://localhost:8080/api/v1/courses
```

Или через Postman:

- **GET** `http://localhost:8080/api/v1/courses`
- Должен прийти пустой список `[]` или список курсов.

## Полезные команды

``` bash
# Остановить приложение в IDEA: красная кнопка ⏹ в консоли запуска

# Остановить PostgreSQL:
docker-compose down

# Посмотреть логи контейнера PostgreSQL:
docker-compose logs -f postgres

# Перезапустить БД с чистыми данными:
docker-compose down -v
docker-compose up -d

# Собрать проект без запуска:
./mvnw clean package

# Запустить тесты:
./mvnw test
```
